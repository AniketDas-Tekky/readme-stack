# T2 — Mode resolution

Parent plan: `plans/readme-generation.md` (section "Mode resolution"). Depends on T1 (scaffolding).

## 1. Goal
Implement `resolve_mode()`: a **pure, I/O-free** function in `core/` that maps (a) a snapshot of the
existing docs state and (b) the relevant CLI flags to either a runnable `ModeDecision`
(CREATE / RECREATE / UPDATE / DIFF_UPDATE) or a typed error carrying the right exit code
(REFUSE → 4, `--diff` without our format → 4, newer format → 3). No git, filesystem or LLM access:
Preflight gathers the facts (via `publishing/manifest_store.py`, later task), this function decides.

## 2. Files
| File | Action |
|---|---|
| `src/readme_stack/core/modes.py` | new: `Mode`, `DocsSnapshot`, `ModeDecision`, `resolve_mode()` |
| `tests/unit/core/test_modes.py` | new: table-driven tests |

No other files are touched. (`tests/unit/core/__init__.py` is not needed if T1 configures pytest
with rootdir-based discovery; if T1 uses packages for test dirs, T1 creates it.)

## 3. Public interface

```python
# src/readme_stack/core/modes.py
from __future__ import annotations

from dataclasses import dataclass
from enum import StrEnum

from readme_stack.core.errors import EnvironmentConfigError, RepoStateError, UsageError
from readme_stack.core.models.manifest import FORMAT_VERSION, MANIFEST_FILENAME


class Mode(StrEnum):
    """Runnable pipeline modes. REFUSE/ERROR are never returned; they are raised."""
    CREATE = "create"            # nothing generated yet; write README + pages from scratch
    RECREATE = "recreate"        # regenerate everything; old README (if any) fed to Explorer
    UPDATE = "update"            # incremental: diff manifest.source_commit..HEAD
    DIFF_UPDATE = "diff_update"  # incremental over the user-supplied --diff range


@dataclass(frozen=True, slots=True, kw_only=True)
class DocsSnapshot:
    """Facts about existing generated docs, gathered by Preflight. No behavior besides validation.

    docs_dir:                repo-relative POSIX path of the docs dir (used only in messages).
    readme_exists:           README.md exists at repo root.
    readme_marker_version:   N from `<!-- generated by readme-stack vN -->`, None if no marker
                             (or README missing).
    docs_dir_exists:         the docs dir exists (as a directory).
    manifest_present:        `<docs_dir>/.readme-stack.json` exists as a file.
    manifest_format_version: `format_version` read leniently (int from a JSON object) even if the
                             rest of the manifest fails validation; None if absent/unreadable.
    manifest_valid:          manifest parsed AND validated against the current schema. Only
                             meaningful when manifest_format_version == current version.
    manifest_source_commit:  `source_commit` from a valid manifest, else None.
    """
    docs_dir: str
    readme_exists: bool
    readme_marker_version: int | None
    docs_dir_exists: bool
    manifest_present: bool
    manifest_format_version: int | None
    manifest_valid: bool
    manifest_source_commit: str | None

    def __post_init__(self) -> None:
        """Raise ValueError on impossible combinations (programming errors, not user errors):
        - readme_marker_version is not None and not readme_exists
        - manifest_present and not docs_dir_exists
        - manifest_format_version is not None and not manifest_present
        - manifest_valid and (not manifest_present or manifest_format_version is None
          or not manifest_source_commit)
        - readme_marker_version / manifest_format_version < 1
        """


@dataclass(frozen=True, slots=True, kw_only=True)
class ModeDecision:
    """Result of resolve_mode().

    mode:                     the pipeline mode to run.
    reason:                   one-line human explanation, logged at INFO by Preflight.
    readme_is_foreign:        an existing README without our marker will be replaced; its
                              content is fed to the Explorer.
    needs_readme_clean_check: Preflight MUST verify README.md is tracked and clean in git and
                              raise RepoStateError (4) otherwise. True iff readme_is_foreign
                              and not force.
    docs_dir_unowned:         --force was used over an existing docs dir with an absent/invalid
                              manifest; later stages may overwrite colliding files there.
    base_commit:              UPDATE only: manifest.source_commit (reachability is checked later
                              by the Impact stage; unreachable → full-review update).
    diff_range:               DIFF_UPDATE only: the --diff value, passed through unvalidated
                              (range validation is Preflight/git, exit 3).
    """
    mode: Mode
    reason: str
    readme_is_foreign: bool = False
    needs_readme_clean_check: bool = False
    docs_dir_unowned: bool = False
    base_commit: str | None = None
    diff_range: str | None = None


def resolve_mode(
    state: DocsSnapshot,
    *,
    diff_range: str | None,
    force: bool,
    recreate: bool,
    current_version: int = FORMAT_VERSION,
) -> ModeDecision:
    """Decide the run mode. Pure: same inputs → same output, no I/O.

    Raises:
        UsageError (2):             diff_range == "" or (diff_range and recreate) — defensive,
                                    the CLI already rejects these.
        EnvironmentConfigError (3): manifest or README marker is from a newer format.
        RepoStateError (4):         --diff without our current format; docs dir exists with an
                                    absent/invalid manifest and not force (REFUSE).
    `current_version` exists only so tests can exercise "older format" while FORMAT_VERSION == 1.
    """
```

Private helpers (not exported, names indicative): `_ManifestState` enum
{`ABSENT`, `UNOWNED`, `OLDER`, `OURS`} and `_ReadmeState` enum
{`MISSING`, `FOREIGN`, `MARKER_OLDER`, `MARKER_CURRENT`}, each computed by a small function.
`__all__ = ["Mode", "DocsSnapshot", "ModeDecision", "resolve_mode"]`.

## 4. Detailed behavior and edge cases

### Derived states (after the "newer" check)
- Manifest: `ABSENT` if not present; `OLDER` if `manifest_format_version < current`;
  `OURS` if `== current` and `manifest_valid`; otherwise `UNOWNED` (present but version
  unreadable, or current version but schema-invalid).
- README: `MISSING` if not exists; `FOREIGN` if no marker; `MARKER_OLDER` if marker `< current`;
  `MARKER_CURRENT` if `== current`.
- **Our format** = manifest `OURS` and README `MARKER_CURRENT`.

### Rule order (first match wins)
| # | Condition | Result |
|---|---|---|
| R0a | `diff_range == ""` | `UsageError` (2) |
| R0b | `diff_range` and `recreate` | `UsageError` (2) |
| R1 | `manifest_format_version > current` or `readme_marker_version > current` | `EnvironmentConfigError` (3); **not** overridable by `--force`/`--recreate` |
| R2 | `diff_range` and our format | `DIFF_UPDATE`, `diff_range=…` (empty range → no-op is decided later in Impact) |
| R3 | `diff_range` and not our format | `RepoStateError` (4); **not** overridable by `--force` |
| R4 | `docs_dir_exists` and manifest ∈ {ABSENT, UNOWNED} and not `force` | `RepoStateError` (4) (REFUSE) |
| R4f | same but `force` | continue with manifest treated as ABSENT, `docs_dir_unowned=True` |
| R5 | our format and `recreate` | `RECREATE` |
| R6 | our format | `UPDATE`, `base_commit=manifest_source_commit` |
| R7 | README MISSING and manifest ABSENT | `CREATE` (`--recreate` is a no-op here) |
| R8 | anything else | `RECREATE` |

`readme_is_foreign = (readme state == FOREIGN)` in every returned decision (only possible for
RECREATE). `needs_readme_clean_check = readme_is_foreign and not force`. `docs_dir_unowned` only
set via R4f. A README with an (any-version) marker is never guarded (plan: only foreign READMEs).

### Full state table (no --diff, no --recreate, no --force unless stated)
| Docs dir | Manifest | README | Result |
|---|---|---|---|
| absent | absent | missing | CREATE |
| absent | absent | foreign | RECREATE, foreign, guard |
| absent | absent | marker (current/older) | RECREATE ("marker without manifest") |
| exists | absent | any | REFUSE (4); with --force: missing→CREATE, foreign→RECREATE (foreign, no guard), marker→RECREATE; all `docs_dir_unowned` |
| exists | unowned (invalid / no version) | any | same as previous row |
| exists | older | any | RECREATE (foreign → guard) |
| exists | ours | missing | RECREATE ("README missing") |
| exists | ours | foreign | RECREATE, foreign, guard |
| exists | ours | marker older | RECREATE ("older format") |
| exists | ours | marker current | UPDATE (base_commit); with --recreate → RECREATE |
| any | newer | any | ERROR (3) |
| any | any | marker newer | ERROR (3) |

With `--diff R`: row "ours + marker current" → DIFF_UPDATE; every other non-newer row → ERROR (4).

### Reason strings (for logs; tests don't assert exact text)
CREATE "no existing docs"; RECREATE "README is not generated by readme-stack" /
"README marker without valid manifest" / "README missing but manifest present" /
"docs are from older format vX (current vY)" / "--recreate requested" /
"--force over unowned <docs_dir>/"; UPDATE "updating from <short sha>..HEAD";
DIFF_UPDATE "updating for --diff <range>".

### Error messages (exact; tests assert key substrings)
- R0a: `--diff requires a non-empty git range`
- R0b: `--diff and --recreate cannot be combined`
- R1: `Existing docs use readme-stack format v{found} but this version supports up to v{current}; upgrade readme-stack.`
  (`found` = the larger of the newer versions.)
- R3: `--diff requires existing readme-stack docs in the current format (README marker v{current} and a valid {docs_dir}/{MANIFEST_FILENAME}): {detail}. Run without --diff first.`
  with `detail` ∈ `no README` / `README has no readme-stack marker` / `README marker is v{n}` /
  `manifest missing` / `manifest invalid` / `manifest is v{n}` (first applicable, manifest
  checked first).
- R4: `{docs_dir}/ exists but has no valid readme-stack manifest ({MANIFEST_FILENAME} is {missing|invalid}); refusing to write into a directory readme-stack does not own. Use --force or choose another --docs-dir.`

## 7. Out of scope / deferred
- Building `DocsSnapshot` from disk (marker parsing, lenient manifest read, validation):
  `publishing/markers.py` + `publishing/manifest_store.py` tasks.
- Performing the git-clean check on a foreign README (Preflight task, using `needs_readme_clean_check`).
- Validating/resolving the `--diff` range, empty-range no-op, `source_commit` reachability and the
  full-review fallback (Preflight / Impact tasks).
- CLI flag validation (`--diff` + `--recreate` exit 2 lives in `cli/app.py`; R0 is defensive only).
- Per-file hash status / hand-edited page handling (Commit/ChangeSet tasks).
- Logging: `resolve_mode` does not log; the caller logs `decision.reason`.

## 8. Open questions
1. **Newer README marker** with no/older manifest: this plan treats it as ERROR (3) like a newer
   manifest (the parent plan only mentions the manifest). Conservative: never overwrite output of
   a newer tool. Confirm.
2. **`--diff` over an older format** → ERROR (4) ("run without --diff first"), rather than silently
   upgrading to RECREATE. Confirm.
3. **Marker-without-manifest README** is not git-clean guarded (plan guards only foreign READMEs),
   although it may have been hand-edited. Guard it too?
4. **`--force` over unowned docs dir with README missing** → CREATE (not RECREATE). Only matters
   for logging and whether the Explorer gets an old README (there is none), so harmless.
5. **Manifest present but docs dir is a file / manifest is a directory**: treated by the loader as
   `docs_dir_exists=True, manifest_present=True, version=None` → UNOWNED → REFUSE. Loader task to confirm.
6. Should `DocsSnapshot` live in `core/models/manifest.py` instead of `core/modes.py`? Kept in
   `modes.py` to keep T2 self-contained; moving it is a pure import change.
