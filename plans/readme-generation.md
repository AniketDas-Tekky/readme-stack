# readme-stack — Step 1: CLI & high-level workflow

## Context
The repo is boilerplate for a GitHub Action (`src/readme_stack/main.py` just counts README lines). We're turning it into a Python CLI that uses LLM agents (Vercel AI SDK for Python, package `ai`, public beta, Python 3.12+) to generate documentation for a repository, aimed at technical readers: `README.md` = architecture / big picture, subpages = implementation details. It must handle a repo with no README, a repo with an existing README (update if it's ours, recreate if not), and a commit diff. It uses a direct Anthropic or OpenAI API key.

This step fixes the **CLI surface, mode logic, pipeline stages, agent topology and module layout**. Later steps (separate plans): agent prompts & doc templates, tool implementations in detail, GitHub Action wrapper.

Per CLAUDE.md, once approved this plan is saved to `plans/readme-generation.md` in the repo, and the Break Down stage appends `## Proposed Tasks`.

## Decisions (confirmed with user)
- Output: `README.md` at repo root + subpages in `docs/architecture/` (`--docs-dir` to override). Never touch files we didn't create.
- Ownership manifest `<docs-dir>/.readme-stack.json` (files, sha256, page metadata, `source_paths`, `source_commit`, `format_version`). README carries marker `<!-- generated by readme-stack vN -->` (N = format version). "Our format" = marker + valid manifest.
- Docs dir exists without manifest → refuse unless `--force` / other `--docs-dir`.
- Hand-edited generated files (hash mismatch) → warn and preserve unless `--force`.
- Foreign README is replaced only if tracked and clean in git; otherwise require `--force`. Its content is fed to the Explorer.
- `--diff RANGE` = git ref range; tool runs git itself. `--diff` without existing generated docs → error (exit 4).
- Keys: exactly one of `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` → use it; both → error unless `--provider`; none → error.
- REPO must be the git top level (no monorepo subdirs yet).
- CLI first; `action.yml` becomes a thin wrapper in a later step.

## CLI (argparse, stdlib)
```
readme-stack [REPO=.] [--diff RANGE] [--provider anthropic|openai] [--model ID|provider:ID]
             [--docs-dir docs/architecture] [--force] [--recreate] [--dry-run]
             [--max-pages 12] [--max-tokens 2000000] [--concurrency 4] [-v|-vv] [--version]
```
- `main(argv=None) -> int`; async pipeline via `asyncio.run`. Logs → stderr; `--dry-run` diff → stdout.
- Default models: `{"anthropic": "claude-sonnet-5", "openai": "gpt-5"}` (confirm OpenAI id when building adapter).
- Invalid combos (exit 2): `--diff` + `--recreate`; `--docs-dir` absolute/outside repo/`.`; `--model p:id` conflicting with `--provider`.
- Exit codes: 0 ok/no-op/dry-run · 1 runtime/agent failure · 2 usage · 3 environment (keys, git, bad range, newer manifest format) · 4 repo state blocks run · 5 token budget exceeded (nothing written) · 130 interrupted.

## Mode resolution (`modes.py`, pure function)
| Condition | Mode |
|---|---|
| No README, no manifest, no docs dir | CREATE |
| Docs dir exists, manifest absent/invalid | REFUSE (4) unless `--force` |
| README foreign (no marker), or marker w/o valid manifest, or README missing w/ valid manifest, or older format | RECREATE (foreign README guarded by git-clean check) |
| Marker + valid manifest | UPDATE (= diff `manifest.source_commit..HEAD`; unreachable commit → full-review update); `--recreate` forces RECREATE |
| `--diff` + our format | DIFF_UPDATE (empty range → no-op) |
| `--diff` + not our format | ERROR (4) |
| Manifest from newer format | ERROR (3) |

## Pipeline (`pipeline.py`, Python-driven, deterministic control)
```
Parse → Preflight → [Impact] → Explore → Outline → Write pages (parallel) → Write README → Assemble → Commit / dry-run
```
1. **Preflight** (no LLM): git top-level check, validate range, resolve provider, load DocsState (README, marker, manifest, per-file hash status), resolve mode, build FileIndex (`git ls-files -co --exclude-standard` minus secret/binary denylist and our own outputs).
2. **Impact** (DIFF/UPDATE only): Python maps changed files (`git diff --name-status -M`) to pages via manifest `source_paths` globs + README triggers (top-level dirs, build/entry files, pages added/removed); ImpactAnalyst agent classifies leftovers and may drop or propose pages → `ImpactReport`.
3. **Explore**: Explorer agent (optional ComponentExplorer subagent per component on large repos), seeded with a precomputed tree summary and old README → `RepoModel`. Scoped to affected areas in update modes.
4. **Outline**: Outliner → `DocPlan` (pages, `source_paths`, sections, cross-links); Python validates (page cap, paths in docs dir, globs match, no unowned collisions) with one repair retry. Update modes keep existing page ids/paths; skipped unless pages are added/removed.
5. **Write pages**: PageWriter per page under `asyncio.Semaphore(--concurrency)`; update modes pass existing page + diff hunks with "edit minimally". Hand-edited pages skipped unless `--force`.
6. **Write README**: ReadmeWriter from RepoModel + DocPlan + page summaries.
7. **Assemble** (no LLM): inject markers, validate relative links & code paths against FileIndex/DocPlan (one repair round, then drop broken links with warning), normalize whitespace.
8. **Commit** (no LLM): ChangeSet (create/modify/delete owned-clean/skip hand-edited); dry-run prints summary + unified diff; else atomic writes, manifest last (sorted keys, no timestamps), usage summary.

Budget (`--max-tokens`) checked after every agent call; exceeding → exit 5 before Commit.

## Agents (all use read-only, repo-sandboxed tools; structured Pydantic output)
| Agent | Tools | Output |
|---|---|---|
| Explorer | list_dir, read_file, glob, grep, git_log, explore_component | RepoModel |
| ComponentExplorer (subagent-as-tool) | list_dir, read_file, glob, grep | Component |
| Outliner | list_dir, read_file | DocPlan |
| PageWriter | read_file, grep, glob, list_dir, git_log | PageDraft |
| ReadmeWriter | read_file, list_dir, grep | PageDraft |
| ImpactAnalyst | git_diff, git_show, read_file, grep | ImpactReport |

Sandbox: paths resolved inside repo root (symlink escapes rejected), only FileIndex files readable, secret denylist (`.env*`, `*.pem`, `*.key`, `id_*`, …), binary refusal, windowed/capped reads and grep, git via fixed argv (no shell).

## Deterministic tools (implementation details in a later step)
Principle: Python computes facts and structure; LLMs write prose and make judgment calls. Parsing via tree-sitter (multi-language).

- **Precomputed facts** (Preflight, passed to agents): `project_facts`, `import_graph`, `component_candidates`, `interface_extractors`
- **Code navigation** (agent tools): `code_outline`, `read_symbol`, `find_symbol`, `find_references`
- **Rendered fact blocks & templates**: `{{facts:*}}` placeholders (commands, env vars, dependency diagram, tree) filled by Python; per-page-kind templates rendered from structured writer output
- **Self-check & diff**: `verify` (paths/symbols/links), `diff_symbols` (symbol-based impact mapping), content-hash file-summary cache

## Project structure
Layered ("clean architecture") src-layout package. **Dependencies point inward only**: `cli → workflow → {agents, analysis, publishing} → core`; `infra` implements interfaces defined in `core` and is injected by `workflow`. Rules:
- `core/` and `analysis/` never call an LLM or touch the network → fully unit-testable.
- Only `infra/llm/` imports `ai` (beta SDK isolated behind one adapter).
- Agents never do I/O directly — only via tools; tools are thin wrappers over `analysis/` and `infra/`.
- Prompts and page templates are data files (package resources), not strings in code.
- One agent per module; one pipeline stage per module.

```
src/readme_stack/
  __init__.py            # __version__
  __main__.py            # `python -m readme_stack`
  config.py              # RunConfig, defaults (models, max pages/tokens, docs dir)

  cli/                   # interface layer
    app.py               # argparse, flag validation, main(argv) -> int (pyproject entry point)
    output.py            # logging, progress, usage summary, dry-run diff printing

  core/                  # domain: pure types + rules, no I/O
    errors.py            # exception hierarchy with exit_code
    modes.py             # Mode, ModeDecision, resolve_mode()
    ports.py             # Protocols: LLM, Git, FileSystem, SummaryCache
    models/
      repo.py            # FileIndex entries, ProjectFacts, Component, RepoModel
      plan.py            # DocPlan, PageSpec, PageDraft (structured sections)
      manifest.py        # Manifest, ManifestEntry, format version
      impact.py          # ChangedFiles, ImpactReport

  workflow/              # application layer: orchestration
    pipeline.py          # mode → stage sequence
    context.py           # RunContext (config, injected ports, budget)
    budget.py            # token budget tracking
    stages/              # preflight, impact, explore, outline, write_pages, write_readme, assemble, commit

  agents/                # one agent per module: prompt name + tool set + output_type
    base.py              # AgentSpec, run helper (via core.ports.LLM)
    explorer.py  component_explorer.py  outliner.py
    page_writer.py  readme_writer.py  impact_analyst.py
  prompts/               # *.md prompt files + loader (importlib.resources)

  tools/                 # agent-facing tools (thin wrappers)
    registry.py          # per-agent tool sets
    fs.py                # list_dir, read_file, glob, grep
    code.py              # code_outline, read_symbol, find_symbol, find_references
    git.py               # git_log, git_diff, git_show, diff_symbols
    verify.py            # verify

  analysis/              # deterministic engines, no LLM
    repo_index.py        # FileIndex, secret/binary denylist, tree summary
    parsing/             # tree-sitter language layer + queries/
    facts.py             # project_facts
    imports.py           # import_graph
    components.py        # component_candidates
    interfaces.py        # interface_extractors
    symbols.py           # symbol index, diff → symbols
    impact.py            # changed files/symbols → pages

  publishing/            # rendering + persistence of generated docs
    templates/           # per-page-kind templates
    render.py            # structured sections → markdown
    fact_blocks.py       # {{facts:*}} fill-in
    markers.py           # README marker parse/render
    links.py             # link/path validation
    manifest_store.py    # manifest load/validate/save, hashing, DocsState
    changeset.py         # ChangeSet, atomic writes, unified diff

  infra/                 # adapters for external systems
    llm/adapter.py       # the ONLY `ai` import; implements core.ports.LLM
    llm/providers.py     # API key / provider / model resolution
    llm/fake.py          # FakeLLM for tests
    git.py               # git subprocess wrapper
    sandbox.py           # repo-root path confinement
    cache.py             # content-hash summary cache

  integrations/
    github_action.py     # get_input/set_output (moved from main.py; used in later action step)

tests/
  unit/                  # mirrors package: core/, analysis/, publishing/, cli/, infra/
  integration/           # pipeline per mode with FakeLLM against fixture repos
  fixtures/repos/        # small sample repos (python, ts, go, mixed)
  e2e/                   # opt-in (@pytest.mark.e2e), real API key required
```
- `pyproject.toml`: entry point → `readme_stack.cli.app:main`; add `ai` (pinned exactly), `pydantic`, `tree-sitter` + language pack; register the `e2e` marker, excluded by default.
- `src/readme_stack/main.py` is removed.

## Verification
- Unit tests (pytest, no network): `resolve_provider` table, `resolve_mode` table, CLI flag validation/exit codes, impact mapping, manifest/marker round-trip and hash status, sandbox escape/denylist, assemble link validation.
- Pipeline tests with `FakeLLM` returning canned Pydantic objects against fixture git repos (`tmp_path` + `git init`): CREATE, RECREATE (clean vs dirty README), UPDATE no-op, DIFF_UPDATE touching one page, `--dry-run` writes nothing, budget exceeded → exit 5.
- `uv run ruff check && uv run ruff format --check && uv run pytest`.
- Manual smoke: `ANTHROPIC_API_KEY=… uv run readme-stack --dry-run -v` on this repo, then a real run, then `--diff HEAD~1..HEAD`.

## Risks
Large-repo context (precomputed tree, windowed reads, component subagents, per-page slices) · cost (token budget, deterministic impact narrowing, no-op detection, dry-run) · beta SDK churn (single adapter, pinned version) · PR noise (stable outline, minimal edits, deterministic manifest) · secret leakage (index + denylist) · hallucinated links (assemble validation) · shallow CI clones (clear `fetch-depth: 0` error).
